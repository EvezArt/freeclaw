# FreeClaw — Open-Source AI Agent

A fully open-source AI agent built on the ClawBreak platform. Basic local usage does not require a paid API key.

The project is designed to degrade gracefully when external model providers, credits, or network services are unavailable. Local functionality must not be described as live provider execution.
